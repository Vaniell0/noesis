# A1 pilot Step 1 — verdict, 2026-07-31

**Verdict: PASS with narrow scope.** The pilot converged cleanly (CE
1.70 → 0.02 over 7 741 opt-steps, one epoch, ~7 h wall), the merged
LoRA checkpoint loads and generates coherently, and A0 held-out eval
shows a **domain-specific gain** on task classes that resemble the
training corpus (function-calling / scheduling) with a paired
**out-of-domain regression** on prose-answer classes. Behaviour is
consistent with a small-model SFT that reshapes the response
distribution more than it teaches new competencies — which is what
Step 1 was budgeted to check.

Track A1 does **not** unlock A2 or C2 on this verdict alone; a
follow-on pass on a mixed reasoning + action corpus (Variant A) is
required before the "reasoning transfers to weights" claim in the H7
lock can be evaluated.

## Setup

- **Backbone:** RWKV-7 G1d-0.4B, native bf16, `n_layer=24`,
  `n_embd=1024`, `RWKV_HEAD_SIZE=64`.
- **Method:** QLoRA, rank 16 / alpha 32 / dropout 0, targets
  `receptance` + `key` + `value`. AdamW lr=3e-5, warmup 200, weight
  decay 0.01, batch 1, grad-accum 8. `RWKV_TRAIN_TYPE=infctx`,
  `chunk_ctx=1`, DeepSpeed stage 1.
- **Corpus:** `training/tokenised/glaive_v2_train.pt` — 61 934
  glaive-function-calling-v2 rollouts, 11.8 M tokens, 19.7 %
  supervised (per-token loss mask, 0 = ignore / 1 = supervise). Custom
  `.pt` schema `{ids, loss_mask, starts, vocab}` shimmed into the
  vendored `sft` loader via `training/noesis_dataset_patch.py`.
- **Regularisation:** `state_reg.mode='off'`, `alpha=0.0` (Step 1
  baseline CE). Patch installed but inactive; step 2 & 3 exercise it.
- **Hardware:** Selectel Cloud preemptible 4090 24 GB, 43 RUB/h. Full
  epoch completed without preemption; no separate merge step needed
  (vendored trainer merges LoRA into the saved `.pth` on epoch save).
- **Artefacts:** `training/runs/pilot_g1d_glaive_v2_a0/rwkv-0.pth`
  (902 MB, on the VM only — not committed), full loss trajectory
  captured at `experiments/A0_eval/results/pilot_g1d_04b_glaive_2026_07_31.loss_data.jsonl`.

## Convergence

- Opt-steps: 7 741 (one epoch = 61 933 micro-batches / 8).
- Loss: start 1.703, end 0.021 (three-step tail mean 0.041).
- Wall: 7 h 01 min at ~2.05 it/s. No divergence, no NaN, no crash.

## What this changes about A1

1. **Training pipeline works end-to-end** on a spot 4090 with the
   `.pt` schema shim and the vendored `train.py`. Reproducible from
   `training/config/pilot.yaml` + `training/train_pilot.py`. Any
   future A1 relaunch on a different corpus reuses this scaffold as
   is.
2. **The A1 target signal is measurable on A0.** The mixed +33 / -50
   pp readout means the eval discriminates action-shaped vs
   prose-shaped responses — good, it's what we want. Follow-on
   corpora should target the specific classes the pilot regressed on.
3. **glaive-v2 alone is not enough for the H7 falsifier.** Under H7
   (understanding-in-weights, knowledge-in-context) a passing A1
   would leave prose-reasoning intact and lift structured-action
   accuracy. Half of that held. The regression on `sym_alg_*`
   suggests a Variant A corpus that mixes tool-call traces with
   restructured open reasoning traces is the actual A1 target — see
   `docs/training-data-shortlist.md` for the shortlist Variant C the
   pilot drew from.
4. **The pipeline is ready to test state_reg (Steps 2 + 3).** Merged
   LoRA loads without a separate merge script (vendored trainer does
   it on save); the state_reg patch is already installed and gated
   on `mode` / `alpha`, so Step 2 sanity (mode active, alpha=0) and
   Step 3 sweep (alpha > 0) run against the same driver with only a
   yaml swap.

## What this does NOT change

- **H7 remains untested.** The pilot corpus lifts action-form
  accuracy and depresses prose-reasoning accuracy — this is the SFT
  shape effect, not evidence about whether reasoning fits in the
  0.4B weight space vs the context window. The H7 falsifier requires
  Variant A + a retrieval-parity contrast (see HYPOTHESES.md §H7).
- **Bit-decoding stays flat (0/16 → 0/16).** Consistent with the H12
  working-memory bottleneck reading: the failure is architectural,
  not a training-data gap. Do not attempt to lift bit-decoding via
  more SFT — attempt it via H12b LoRA + utilisation regulariser.
- **A1 remains open on ROADMAP.** Step 1 discharges the pilot
  scaffolding milestone; Steps 2 + 3 remain, and the H7 falsifier
  ("Variant A + retrieval-parity eval") remains the actual A1
  success gate for Gate 2.

## Sequel plan

Ranked by cost:

1. **Step 2 sanity** — `mode=trajectory_reg`, `alpha=0.0` on the
   dry-run corpus. Config at `training/config/pilot_step2_sanity.yaml`.
   Ran in the same session; completed in 42 s wall / 12 opt-steps on
   the 4090. CE trajectory matched Step 1's dry-run (no divergence,
   no NaN, sum_loss=1.170 by end of the 99 micro-batches — expected
   for a dry-run window). **However**, `light_rwkv_state_reg_patch.py`
   currently short-circuits on `alpha == 0.0` and prints "INACTIVE"
   regardless of `mode`, so Step 2 as run did *not* exercise the
   hook infrastructure — the training_step never got monkey-patched.
   Step 2 as originally spec'd needs the patch's alpha gate lowered
   to `alpha > 0` (or the mode gate promoted) to actually validate
   the hooks. Follow-up: fold the mode-vs-alpha decision into Step 3
   with a nominal `alpha=1e-6` first-step to prove hooks are live,
   then sweep upward.
2. **Step 3 alpha sweep** — `alpha ∈ {1e-3, 1e-2}` on the same short
   corpus (~30-60 min each). Threshold: pass if CE tracks Step 1
   within ±5 %, fail if state RMS on `{L12, L16, L20}` diverges > 2×
   (kill switch from `state_reg.py` docstring).
3. **Variant A corpus prep** — restructure open-reasoning traces
   into tool-shaped steps per `docs/training-data-shortlist.md`
   §Variant C → Variant A upgrade. Then rerun the full pilot on the
   mixed corpus; that is the H7 falsifier.
4. **A0 eval expansion** — the four items where the pilot's `<think>`
   block truncated inside a correct answer suggest raising
   `num_predict` from 2048 to 4096 on the pilot run and re-scoring.
   Cheap re-scoring pass, no new training.

Steps 2 + 3 fit in the remaining pilot rental window (~1 000 RUB /
~23 h). Variant A is a next-rental-cycle item.
